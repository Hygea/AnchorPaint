# AnchorPaint v0.1.0

First experimental release · 2026-10-24.

**[Open AnchorPaint](https://hygea.github.io/AnchorPaint/)** — no installation or
account required. This release records the first tested public version; the
hosted app follows main and may receive later updates. The v0.1.0 tag preserves
this version's source.

AnchorPaint creates aligned slicer modifier volumes from selected STL features.
Load a model, select a supported post or wall, choose the depth and export one
3MF without manually positioning primitives. Processing happens in the browser.

## Included

- Local STL loading, millimetre confirmation and axis-aligned printing orientation.
- Smart Fill selection for isolated solid/hollow round posts and straight walls,
  including supported straight shafts below shaped caps.
- Automatic footprints, holes, base height and local depth/overlap limits.
- Sliders, precise inputs, modifier preview, multiple targets and remove/undo.
- Aligned 3MF export with a stock preset or optional custom native Bambu settings.

## Compatibility and limits

The public site passed a live Chrome test covering selection, numeric controls,
visible modifier preview, aligned 3MF export and original mesh preservation.
No model uploads, browser errors or failed asset requests were observed during
that test. Geometry/export tests and the hosted build/deployment checks pass.

Bambu Studio 2.8.2.61 has documented repeated native import/save and selected GUI
slicing checks. OrcaSlicer 2.4.2 portable has a maintainer-reported working import
and slicing test with a vertical-shell-thickness substitution warning. PrusaSlicer,
other versions, full comparative layer behavior and physical strength remain
unverified. [Detailed coverage](../../TEST_STATUS.md).

Tapers, filleted roots, sloping bases, joined/branching features, mesh repair and
freehand painting are outside this preview. Modifiers do not reshape the STL.
Choose your actual printer/material and inspect sliced layers before printing.
