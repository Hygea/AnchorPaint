# AnchorPaint v0.1.0 — draft release notes

**Draft only. Do not publish until licensing/privacy decisions, owner approval
and live deployment acceptance are complete. This preparation created no tag
or GitHub Release.**

AnchorPaint is a free browser-based experimental tool for creating aligned slicer
modifier volumes from selected STL features. Load a model, select a supported
side surface and set the modifier depth without positioning primitives by hand.

Planned web app: https://hygea.github.io/AnchorPaint/ — not verified live yet.
Pages is the primary distribution; no desktop installer is included.

## Included

- Local STL loading, millimetre size confirmation and optional axis-aligned
  printing orientation from a selected bed face.
- Click/Smart Fill selection for isolated round solid/hollow bosses and straight
  rectangular walls on horizontal bases; supported straight shafts beneath caps.
- Automatic footprint, base-height and available-depth checks, including holes.
- Shared depth/overlap sliders and wall count, immediate preview, multiple
  modifiers, remove/undo and aligned 3MF export.
- Bundled stock Bambu export settings and an optional custom settings source.
- In-browser processing with no model-upload service, account or backend.

## Compatibility evidence

- **Bambu Studio 2.8.2.61:** actual repeated import/save checks for documented
  fixtures/parts, plus selected native GUI modifier/slicing checks. Full
  comparative layer and physical-strength validation remain open.
- **OrcaSlicer 2.4.2 portable:** user reports working placement, wall overrides and
  slicing. Import warns about newer configuration and replaces
  `ensure_vertical_shell_thickness=enabled` with `ensure_all`. Save/reopen and
  other versions are unverified; identical toolpaths are not claimed.
- **PrusaSlicer and other slicers/versions:** untested.

## Limits and printing reminder

Tapers, fillets at roots, sloping bases, joined/branching features, general mesh
repair and freehand painting are outside this MVP. Input must pass the current
mesh checks. Modifiers are separate settings regions, not changes to the source
STL surface. STL is interpreted as millimetres after confirmation.

**Select your actual printer/material and inspect sliced layers before printing.**
Previewing or downloading a modifier does not guarantee stronger or safe parts.
No desktop integration, G-code generation or print sending is included.
