## Bundled stock preset

The default 3MF settings asset is generated by Bambu Studio 2.8.2.61 from stock
P1S 0.4 mm, PLA Basic and 0.20 mm Standard presets. The source includes printer
start/end and other templates as well as numeric configuration. Bambu Studio's
upstream repository licenses its material under GNU AGPL version 3; the preset
material is retained under those terms separately from the original MIT app.
No special permissive exception is assumed for saved projects or free tools.

This distribution includes:

- [Full upstream AGPL license](../public/licenses/BambuStudio-AGPL-3.0.txt).
- [Editable resolved configuration](../public/preset-source/default-settings.json).
- [All 17 unchanged source JSON presets/templates and a manifest](../public/preset-source/manifest.json).
- The original regeneration recipe and an offline repackaging tool described in

The snapshot was compared against upstream revision

The full license and editable sources are copied into the static site with the

The website's Licenses & credits link exposes the license/source information.

## Why the preset exists

The geometry algorithm does not depend on a P1S printer. Native Bambu project
recognition and a usable settings payload are required by the current export
path to preserve wall-loop overrides. Native tests rejected profile-free output.
The stock preset avoids requiring a starter project; custom native settings remain
optional. Switching to a different vendor's preset would not itself eliminate
third-party licensing obligations.

## Project sharing and license scope

Bambu documents sharing 3MF print profiles on MakerWorld. That supports project
sharing as an intended workflow, but does not supply a separate license exception
for copying stock templates into a reusable application. The GNU license guidance
also distinguishes ordinary output from copied licensed material in output.
The conservative approach here is to retain upstream terms, notices and source
for the bundled material rather than claim it as original MIT work.

This is a documented compliance approach based on published upstream terms, not
an opinion on every possible derivative/aggregation scenario. It does not impose
a license on the user's original model. Anyone redistributing third-party preset
material should retain its applicable terms and source/notice information.
